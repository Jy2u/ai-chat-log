# AI 对话记录器

复制文字或图片后，用悬浮条记成提问或回答。课题、文件夹、会话、思维导图、文档和待办都在本机，关掉窗口会缩到托盘。

## 当成软件来用

1. 把整个项目文件夹放到电脑上（不要只拷其中一个文件）。
2. 打开这个文件夹，右键 **启动** → **发送到** → **桌面快捷方式**。
3. 可选：右键桌面上的快捷方式 → **属性** → **更改图标** → 选本文件夹里的 `app.ico`。
4. 以后双击桌面图标即可。也可以把快捷方式钉到任务栏。

关掉窗口不会退出，只是缩到右下角托盘。要彻底退出，请右键托盘里的图标选退出。

齿轮 **设置** 里可以打开开机自启（开机后静默待在托盘），也可以暂停记录。

---

## 记录对话

在别的软件里复制文字或图片，屏幕上会弹出悬浮条：

- **提问** / **回答**：写入当前会话
- **×**：这次不记

密码管理器复制出来的内容默认不会记录。

---

## 左侧：课题、文件夹、会话

左边默认收成一条细边，鼠标移上去展开，移开收回。收起时不会挡住中间的对话按钮。

- **课题**：左上角课题列表空白处或课题上右键可新建。点课题切换工作区，双击改名，可拖动排序。
- **文件夹**：用来按周期或主题收纳会话。右键文件夹可在里面新建会话 / 导图 / 文档，或下载整个文件夹。
- **会话**：点开中间就是气泡流。双击改名；可拖到文件夹里。条目下方会显示创建时间和最后编辑时间。
- **思维导图 / 文档**：同样可双击改名、拖动；条目下方也会显示创建时间和最后编辑时间。

右键会话还可以：

- 添加备注；鼠标停在这条对话上会显示备注
- 贴标签：【cursor】/【codex】二选一，以及【已完成】（未完成不显示）。标签画在对话气泡外面的右侧，不挤进条目里
- 导出这一条为 Markdown
- 若已做颜色匹配：导出同一颜色的全部对话（会得到一个 md 文件夹，图片在 `images/`）
- 在此会话下新建思维导图、文档
- 复制 / 移动到其他文件夹或课题
- 删除（进回收站）

### 颜色匹配

文件夹右侧有 **【匹配】**：

1. 点一次，进入点选；再点要绑在一起的会话
2. 再点【匹配】，选颜色
3. 同色会话会一起高亮

Esc 或空选再点一次【匹配】可退出。右键会话可取消颜色匹配。

## 中间：聊天、导图、文档

- **聊天**：回看气泡。气泡上的链接可复制原文、改角色等。若整段是 Cursor Canvas 的 JSX（带 `from "cursor/canvas"`），会排成卡片和表格，而不是整段代码。
- **思维导图**：中键拖动可框选（框到的单元和连线能一起拖），拖背景移动画面，Ctrl + 滚轮缩放。右键节点可看创建时间和最后编辑时间。
- **文档**：左侧写 Markdown，右侧预览。工具栏「markdown语法」可查看写法。

顶栏搜索框可搜全部记录，回车确认；清空搜索框回到原来的页面。

**回收站**里的内容可以恢复，或彻底删除。

## 右侧：待办

- 输入后点 **+** 或回车添加
- 写成 `年-月-日-事情`（例如 `2026-09-11-交报告`）会自动拆出日期；同一天的会归在一组，日期颜色按天轮换
- 每天里面再分成未完成和 **已完成**；点圆圈完成后，条目会移到下面的已完成
- **单击**一条待办：在标题下写备注（小字）；回车保存，Esc 取消
- **圆圈**：标记完成；再点一次会移回未完成
- **右键**：标为【延后】或【不做了】，条目标顶会出现对应的玻璃标记；再选一次或选「取消标记」可去掉
- **×**：删除

## 底部：常用

窗口最底下整行。左边方形玻璃框切换分类，右边只显示这一类。

- **提示词** / **密钥** / **账号密码**（默认打开提示词）
- 在当前分类里输入内容后点 **+**
- **单击**卡片复制；**双击**编辑；**×** 删除

只存在本机。底栏上沿可拖动改高度。

---

## 导出和备份

- **导出 Markdown**：右键当前会话或文档
- **下载整个文件夹**：右键文件夹，打成 zip（对话 / 导图 / 文档 / 图片）
- **备份整个软件**：拷一份程序和数据库，换电脑也能接着用

记录保存在本文件夹的 `data` 里（数据库 + 图片）。备份或换电脑时把整个项目文件夹一起带走即可。
